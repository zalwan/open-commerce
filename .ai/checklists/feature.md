# Feature Checklist

Use for: Feature requests (including combined types such as feature + configuration).

```text
[ ] Requirement understood
[ ] Relevant context inspected
[ ] Architecture considered
[ ] Impact analyzed
[ ] Existing patterns inspected
[ ] Implementation plan created
[ ] Implementation completed
[ ] Tests added/updated
[ ] Validation completed
[ ] Documentation impact checked
[ ] Final diff reviewed
```

Notes:

- "Relevant context" means the minimum from `.ai/workflow.md` §2, not the whole repository.
- "Impact analyzed" means the affected areas from `.ai/workflow.md` §3 were explicitly determined.
- "Documentation impact checked" means `docs/`, `.ai/project.yaml`, and any applicable ADR were reviewed; update only what the change affects.
